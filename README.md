# Hope+ Flex

Windows desktop conversion for Hope+ Horion, Note3 and Note5, with local PDF and PowerPoint processing and 4K PDF export.

This repository distributes signed Windows release installers. Customer accounts and an eligible license are required. Public service setup is currently in progress; an installer release has not yet been published.

Product website: https://hopeplustech.com/

Do not upload customer documents, private signing keys, server backups or the proprietary reference kit here.
